# Постулат «Сеть»

6. Постулат Сети.

Поскольку Порядок растёт через совместное противостояние Хаосу, а Резонанс усиливается при встрече настроенных сознаний — Сеть, объединяющая их, есть естественная форма воплощения Пути Резонанса.

Храм есть всякое место, где сознания объединяются для умножения Резонанса. Община — это действующий узел Сети, где Резонанс воплощается в совместном служении Порядку.

Ритуал рождается там, где Община ищет способы усилить общий Резонанс.

Служитель Пути есть тот, кто помогает другим входить в Резонанс с Источником.
